使用指南

这是什么

这是一个面向仓储、门店、小型团队的轻量级盘点与运营工具。支持 Excel 导入账面库存、扫码/摄像头录入实盘、仓库可视化、机台毛利与品类分析，并自动计算差异与导出报告。

为什么做这个

传统盘点要么人工抄写 Excel，要么部署一套动辄几万块的 WMS。我们见过太多老板最后用「纸 + 计算器」凑合，于是做了这个零部署、零成本、双击就能用的工具。

  • 缓解手动盘点带来的数据准确性问题（每扫一次自动 +1，扫码枪 / 摄像头双通道）
  • 提升盘点效率（条码识别 ≤ 200ms，无须手动敲数量）
  • 导出结果直接给财务、店长复核，无需额外学习

推荐工作流

  1. 仓库看板：汇总盘点执行、仓库库存、滞销消耗的实时数据
  2. 数据导入：上传账面库存 Excel　→　扫码盘点：扫码录入实盘
  3. 盘点明细：逐条核对 / 修正实盘数量
  4. 盘点数据：盘点前账面库存 / 已保存盘点报告 / 账面比对
  5. 仓库管理 / 机台数据：按需使用可视化、单据、毛利与品类模块

数据与隐私

所有业务数据默认保存在你的浏览器本地存储（localStorage）中，不主动上传到任何外部服务器。清除浏览器站点数据会丢失本地记录，建议每次盘点结束后导出 Excel 留底。

安全声明

  • 本系统为本地优先工具，请在可信设备与浏览器环境中使用。
  • 请勿在公共电脑长期保存含敏感业务数据的本地缓存；使用完毕可导出后清理站点数据。
  • 上传的 Excel、单据图片仅在本机处理与存储；请确保文件来源可信，避免打开来历不明的附件。
  • 通过摄像头扫码时，浏览器可能请求媒体权限；权限仅用于扫码识别，不会用于其他用途。
  • 如通过 http:// 局域网部署，请限制访问范围，避免未授权人员访问业务页面。

常见问题

摄像头扫码不工作？

本工具使用浏览器原生 API，file:// 协议下摄像头会被浏览器阻止。请用 Chrome / Edge 打开并通过 http:// 访问（局域网或本机 Web 服务器均可）。

Excel 格式要求？

必须包含「商品编号」「库存数量」两列；可选「商品名称」「条形码」「商品分类」。可在「数据导入」页直接下载模板。

扫到商品没有条形码？

系统会提示你扫描条形码，扫完自动补录到该商品上，下次再扫同样条码即可直接命中。

盘点后怎么和账面对比？

到「盘点数据 → 账面比对」选择一份已保存的盘点报告（或当前未保存数据），点「开始比对」。系统会按商品编号逐条比对盘点前账面库存与实盘数量，给出对平 / 盘盈 / 盘亏 / 未盘点 / 账面缺失五种结论，并支持导出 Excel。
